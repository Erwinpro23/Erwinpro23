### 🚦 Smart Traffic ALPR-VN
Real-time **vehicle detection & Vietnamese license plate recognition** on traffic video, GPU-accelerated.
- **YOLO11s + ByteTrack** for 4 vehicle classes, **YOLOv9s** plate detector
- OCR with syntax check on 63 province codes + **multi-frame voting**
- **CUDA Graphs + ONNX Runtime GPU**, live web dashboard & CSV export
- 📊 **86.2%** plate accuracy (4K) · **29–58 FPS** (1080p) · **>92%** vehicle-type accuracy
